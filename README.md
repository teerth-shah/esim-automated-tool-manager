# eSim Automated Tool Manager

## Features
- Tool detection
- Version checking
- Tool installation
- Verification
- Status reporting
- Logging

## Requirements
Python 3.x

## Installation

git clone <your-repository>
cd <project>

## Run

python main.py

## Usage

1. Check Tools
2. Check Versions
3. Install Tool
4. Verify Tool
5. Show Status
6. View Logs
7. Exit
